# LOCKD map, identity artwork and private backend release

This is the acceptance record for the 5 November continuation. It does not certify the entire marketplace as production-ready.

## Customer interface

- Replaced header and footer artwork across all 15 root HTML pages with `assets/brand/lockd.svg`, a native path-based trace of the supplied logo. No raster image is embedded. The favicon uses its matching symbol. The vector artwork was rasterized locally for visual inspection and matches the supplied identity.
- Applied the reference's warm surface, burgundy, rounded controls and card treatment through `brand-refinement.css`, preserving existing typography, authentic listing photos and account flows. No theme toggle or invented notification badge was introduced.
- Rebuilt the homepage map workspace in `discovery-map.mjs` and `discovery-map.css`: location/date/quantity summary, existing-category shortcuts, existing filter form, list/map control, synchronized real-result sidebar and price markers, selected rental card, narrow-screen result rail and empty/error/loading states.
- The map opens lazily as its section comes into view, unless a shared URL selects list view. The header changes surface subtly while discovery is visible. Existing location state, cookies, real place search and browser permission behavior are reused.
- Replaced Positron with OpenFreeMap Liberty, removed the background-layer colour override and disabled cooperative-gesture prompts. Mouse-wheel movement scrolls the page; drag, pinch and zoom controls operate the map. No user coordinate, pin, rental, price, rating or review was fabricated.
- The actual public map endpoint remains the authoritative catalogue query. Dates, guests, quantities, prices and category values retain the existing backend validation. Unsupported instant-book, ratings, amenities and notification controls from the reference were not presented as working features.
